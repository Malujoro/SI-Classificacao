# 📘 Estudo Comparativo de Técnicas de Classificação de Gliomas Cerebrais Baseadas em Dados Clínicos e Mutacionais

Este repositório contém o código utilizado para realizar análises e experimentos presentes no estudo.  
O projeto foi desenvolvido no **Google Colab**, permitindo que qualquer usuário execute tudo sem necessidade de instalação local.

---

## 🚀 Como executar o projeto

### 1️⃣ Abrir no Google Colab
Você pode executar o notebook diretamente no navegador:

1. Acesse o arquivo principal do projeto (`Codigo.ipynb`)  
2. Clique em **"Open in Colab"** ou abra manualmente via:  
   **Colab → Arquivo → Abrir notebook → GitHub → cole a URL do repositório**

---

## ▶️ 2️⃣ Executar o notebook

Após abrir no Colab:

1. Vá em **Ambiente de execução → Conectar**  
2. Em seguida, clique em **Ambiente de execução → Executar tudo**

O Colab irá:
- instalar bibliotecas necessárias,
- carregar dados,
- treinar modelos,
- gerar os resultados.

---

## 📦 Dependências

Todas as dependências que não estão presentes no ambiente do colab são instaladas automaticamente pelo notebook.
